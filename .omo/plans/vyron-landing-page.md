**What you'll get:** A premium, dark, cinematic VYRON landing page served by the existing web app: ten sections (hero through final call-to-action) with the exact copy you supplied, a static concept illustration of the four-floor digital headquarters, working in-page navigation, and an honest "early access" email link instead of a fake signup.

**Why this approach:** The web app is an empty stub whose framework was already decided (Next.js + Tailwind), so the landing page becomes its first real page rather than a separate site. **What it will NOT do:** No 3D rendering, no signup form or database, no invented customers, metrics, testimonials, or live counters. No login or dashboard. No changes to the API or shared packages.

**Effort:** Medium
**Risk:** Low - all static; only risk is Next.js/Tailwind scaffold friction inside a Bun workspace with TypeScript 7 (mitigated: Next 16 build with TS 7 was verified in a scratch project).
**Decisions to sanity-check:** early-access email is a placeholder `hello@vyron.ai`; wordmark is plain text (no logo file exists); capabilities are split into "Current" vs "Vision" labels as the honesty rule demands.
