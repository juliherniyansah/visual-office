# apps/web

## OVERVIEW
Next 16 App Router dashboard + three.js office scene. React 19, zustand 5, Tailwind 4, jwt-decode. Port 3100.

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Landing page | `src/app/page.tsx` + `src/components/landing/` | content in `src/lib/site.ts` |
| Login | `src/app/login/page.tsx` | |
| First-run setup | `src/app/setup/page.tsx` | largest page |
| Dashboard | `src/app/dashboard/` | own layout |
| 3D office | `src/components/office/` | root `OfficeCanvas.tsx` + split 3D components |
| API client | `src/lib/api.ts` | talks to apps/api |
| Auth context | `src/lib/auth.tsx` | JWT decoded client-side |
| GLB models | `public/models/` | generated by `apps/assets`, don't hand-edit |
| E2E | `e2e/` | Playwright; `global-setup.ts`, `setup-global-setup.ts` |

## CONVENTIONS
- Tailwind 4 CSS-first (`@tailwindcss/postcss`), no tailwind.config.
- Client-decoded JWT is display-only; real auth enforced by API/socket.
- E2E naming mixed: `*.e2e.ts` and `*.spec.ts` — both run by Playwright, not `bun test`.

## ANTI-PATTERNS
- Don't import mongoose/server packages here; only `@redhunter/shared` types/schemas.
- Don't commit `.next/`.

## COMMANDS
```bash
bun run dev        # next dev -p 3100
bun run build
bun run e2e        # playwright test
```
